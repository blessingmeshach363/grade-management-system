# grade-management-system
Python-based Student Grade Management System with features for tracking, analyzing, and reporting student performance. Ideal for educational institutions and programming beginners.
# 📚 Student Grade Manager System

![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-stable-brightgreen)

A comprehensive student grade management system built with Python that allows educators to efficiently manage and analyze student performance data.

## ✨ Features

- ✅ **Add New Students** - Easily add students with their grades (0-100)
- 📊 **Display All Records** - View all students with their grades and pass/fail status
- 📈 **Class Average** - Calculate the overall class average
- 🏆 **Find Extremes** - Identify highest and lowest scoring students
- ⚠️ **Failing Students** - Automatically flag students with grades below 60%
- 🖥️ **Interactive Menu** - User-friendly console interface
